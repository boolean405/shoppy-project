# 🛍️ Shoppy - Vue.js E-commerce Website

A modern and responsive **e-commerce web application** built with **Vue 3, Vuex, Vue Router, Bootstrap 5, and Axios**.  
Shoppy provides a simple yet scalable architecture for managing products, categories, and a shopping cart system.

https://shoppyproject.netlify.app

---

## ✨ Features

- 🛒 **Product Listing** – Browse products with category filtering  
- 📂 **Category Filters** – Filter items dynamically  
- 🛍️ **Shopping Cart** – Add/remove items with Vuex state management  
- 🔄 **State Persistence** – Cart data stored in Vuex  
- 📱 **Responsive Design** – Styled with Bootstrap 5  
- 🌐 **API Ready** – Axios integrated for backend communication  
- 🎨 **FontAwesome Icons** – Modern UI with icons  
- ⚡ **SPA** – Fast single-page navigation with Vue Router  

---

## 🛠️ Tech Stack

- **Frontend:** Vue 3, Vue Router, Vuex  
- **UI:** Bootstrap 5, FontAwesome  
- **Networking:** Axios  
- **Tooling:** Vue CLI, ESLint
